# 商品与定价决策口径

## 1. 字段字典

| 字段 | 含义 | 必要性 |
|---|---|---|
| `product_name` | 商品名称 | 必填 |
| `sales_unit` | 对外销售单位，如杯、份、件、次 | 必填 |
| `purchase_spec` | 采购规格，如 5kg、箱装 24 件 | 成本核算必填 |
| `purchase_price` | 对应采购规格的实付金额 | 成本核算必填 |
| `usage_per_unit` | 每个销售单位的用量 | 成本核算必填 |
| `packaging_cost` | 每个销售单位的包装成本 | 没有包装时填 0 并说明 |
| `waste_rate` / `waste_amount` | 损耗率或每份损耗金额 | 有损耗时必填其一 |
| `per_order_fee` | 平台、支付或配送等按单费用 | 有则填 |
| `selling_price` | 实际收款价，不是划线原价 | 毛利计算必填 |
| `fixed_cost_per_day` | 按天分摊的固定成本 | 保本计算必填 |
| `sales_qty` | 某时间段实际销量 | 复盘时必填 |
| `period` | 数据周期和起止日期 | 复盘必填 |

## 2. 换算与公式

### 采购单位成本

`采购单位成本 = 采购价 ÷ 采购规格中的可用数量`

若采购规格用重量/体积表示，先统一到克、毫升或件，再乘每份用量。无法确认可用数量时，不用行业常数代替。

### 轻量输入口径

进货价对应的单位与销售单位一致时（按份、按个进货），直接取进货价为原料单份成本；不一致时必须按采购规格换算，换算不出就列材料缺口，不用行业常数。目标售价和预计日销量只用于情景比较，不写成经营实绩。

### 单份损耗成本

- 已知损耗率：`原料单份成本 × 损耗率 ÷ (1 - 损耗率)`；同时说明使用的是“损耗后摊回”口径。
- 已知每份损耗金额：直接使用用户确认金额。
- 只有“经常会损耗”这种描述：列为待补，不计算。

### 单份变动成本

`原料单份成本 + 包装成本 + 单份损耗成本 + 按单变动费用`

平台抽佣若按售价百分比收取，写成：`实际收款价 × 抽佣率`，不能先按原价计算。

### 毛利与保本

`单份毛利 = 实际收款价 - 单份变动成本`

`毛利率 = 单份毛利 ÷ 实际收款价`

`日保本单量 = 向上取整(日固定成本 ÷ 单份毛利)`

当实际收款价为 0、成本不完整或单份毛利 ≤ 0 时，不输出百分比或保本单量。

## 3. 情景比较

至少提供“保守 / 基准 / 乐观”中的两个情景，但每个情景的变化必须写清：售价、份量、成本、销量或费用到底改了什么。情景是决策比较，不是预测承诺。

默认比较项：

| 情景 | 适合回答 |
|---|---|
| 成本不变、售价变化 | 价格底线和毛利变化 |
| 售价不变、份量变化 | 是否通过减量保护毛利 |
| 价格与套餐变化 | 客单、折扣和组合毛利 |
| 已有实绩对比 | 调价是否带来可观察变化 |

## 4. 数据质量检查

- 金额是否混用了元、角、分或“每箱/每件”单位？
- 成本和销量是否属于同一日期或周期？
- 菜单价、平台收款价、实际到账价是否被混为一个字段？
- 固定成本是日、周还是月？是否被直接拿来除以日销量？
- 损耗率是否重复计入采购价或报损？
- 套餐是否使用折后实际收款价？
- 是否把预计销量当成实际销量？
- 是否把一日数据写成趋势或稳定结论？

任何检查失败，先输出“口径问题清单”，再决定是否继续计算。

## 5. 价格决策边界

- 没有可量化价值指标时，不使用“价值定价”包装一个拍脑袋价格。
- 少于 30 份问卷时，不把价格敏感度问卷当成统计定论；可以做方向性参考并标明样本量。
- 竞品价格没有来源、日期或截图时，只能作为待核验观察，不进入确定结论。
- 折扣方案必须显示折后毛利和有效期；不能只写“建议打九折”。
- 最终价格由经营者确认；Skill 输出的是范围、情景和验证动作。
