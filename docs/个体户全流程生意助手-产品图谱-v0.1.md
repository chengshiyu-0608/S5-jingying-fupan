# 个体户全流程生意助手｜产品图谱 v0.1

## 一句话定位

给没有时间做管理的小摊贩一条“从想摆摊到每天卖得更好”的行动路线：每一步只给下一件要做的事、所需材料、可直接使用的工具和完成后的判断。

## 收口决定

- **首个城市**：不绑定单一城市；调研时可以先选一个城市做样本，但产品输入必须允许用户自行填写城市。
- **首个用户**：刚准备开摊或开摊 3 个月内的个体户。
- **首个类型**：小吃摊 / 饮品摊（先验证一条真实链路，不同时覆盖所有行业）。
- **核心任务**：找到可行摊位并完成一次低成本试营业，随后用数据决定是否继续、调整或换点。
- **产品形态**：手机优先的“生意路线图”，不是项目管理后台。
- **每一步固定输出**：要做什么 → 需要什么 → 可以用什么工具 → 做完看什么结果 → 下一步。

## 场景库的规模化组织方式

场景库不应该把成千上万个小场景平铺出来。建议采用四层结构：

```text
生意大类
  ↓
经营动作
  ↓
小场景模板
  ↓
行动卡 / 输出物
```

### 第一层：生意大类

第一期先展示 5 个大类入口，名称按经营者的动作来写，不按抽象的企业部门来写：

| 大类 | 小场景示例 | 首期策略 |
| --- | --- | --- |
| 开摊与运营 | 选品算账、选址调研、试营业 | 直接做可用 |
| 经营分析与复购 | 事后经营分析、数据监控、复购判断 | 直接做可用（首期以每日复盘卡实现） |
| 门头与物料 | 推车海报、菜单价签、LOGO、商品主图、摊位拍照 | 海报先做，其他进入规划 |
| 内容与宣传 | 朋友圈宣传、抖音短视频、小红书笔记、开张通知 | 先做内容模板，暂不做自动发布 |
| 客户与成交 | 招呼话术、报价、顾客异议、复购提醒 | 先收集需求，后续深耕 |
| 办事与合规 | 营业执照、食品相关咨询、摊位规则、材料清单 | 只提供官方入口和待确认项 |

### 第二层：经营动作

点击大类后只显示该类的动作，例如“门头与物料”下显示“让顾客看懂”“让摊位更醒目”“让图片能发布”，而不是直接显示几十张卡。

### 第三层：小场景模板

小场景必须能用一句话描述完成结果，例如：

- “给一个饮品摊做一张推车海报”
- “给第一次试营业写一条朋友圈预告”
- “把一个 LOGO 方向做成招牌、杯贴和菜单预览”
- “把顾客说贵了的回应整理成三句现场话术”

### 第四层：行动卡 / 输出物

每个小场景只需要一张卡：输入槽位、下一步动作、输出物、完成判断、相关场景。参考图片底座的“五槽”思路，可把输入统一为：**生意目标、对象、渠道/地点、材料、限制**；不同小场景只改变槽位问题和输出模板。

## 场景库的推荐界面形式

1. 顶部保留一句话搜索：用户可以直接输入“我想做一张饮品摊海报”。
2. 搜索下面展示 5 个大类卡片，每张只放 3—5 个高频小场景示例。
3. 点击大类进入“动作 + 小场景”两列视图；左侧是动作，右侧是小场景模板。
4. 小场景卡要带状态：**可直接开始 / 需要材料 / 规划中**，不能把规划项伪装成可用功能。
5. 每张卡提供“开始”“收藏”“看相关场景”三个入口，不做复杂项目管理。
6. 对于大规模目录，依赖搜索、最近使用、收藏和“根据当前路线推荐”，而不是让用户翻页找场景。

## 首期与大规模目录的关系

首期只把 5 个场景做成完整链路，但界面提前预留其他大类和小场景入口。这样既不会把第一期做得过大，也不会把未来的 LOGO、视频、朋友圈、办事材料等需求硬塞进同一个“新品推广”场景。

## 全流程图谱

```text
想开始摆摊
  ↓
1. 选品与算账
  ↓
2. 选址与人流调研
  ↓
3. 合规与开摊准备
  ↓
4. 摊位、菜单与海报
  ↓
5. 试营业与现场话术
  ↓
6. 本地推广与朋友圈运营
  ↓
7. 事后经营分析与复购判断
  ↺ 根据数据：保留 / 调价 / 换品 / 换点 / 加大推广 / 做复购
```

## 七步路线与第一期五个可用场景

七步路线保留全流程视野，但第一期只把下面五个场景做成可用功能：

1. 选品与算账
2. 选址与人流调研
3. 海报与摊位物料
4. 试营业
5. 事后经营分析

合规办理、朋友圈运营和更丰富的推广能力先保留在路线图中，作为后续扩展，不在第一期承诺完整可用。

| 阶段 | 用户要完成的事 | 助手应提供 | 最小完成证据 |
| --- | --- | --- | --- |
| 1 选品与算账 | 选 1—3 个主卖品，算成本、售价、毛利和保本单量 | 选品问答、成本表、价格带参考、风险提示 | 一张能看懂的单品账 |
| 2 选址与人流 | 比较 2—3 个候选点和时段 | 地图搜索入口、人流观察表、竞品记录、时段建议 | 至少一次现场观察记录 |
| 3 合规与准备 | 知道当地需要办什么、先问谁 | 按城市的办理清单、材料清单、官方入口；明确“以当地要求为准” | 一份办理路径和待办 |
| 4 摊位与物料 | 让路人 3 秒看懂卖什么、多少钱 | 推车海报文案、菜单/价签、尺寸建议、可打印稿 | 一张可打印海报或菜单 |
| 5 试营业 | 在低成本下验证有人买、买什么、为什么买 | 开张清单、招呼话术、优惠机制、缺货应对 | 一次完整试营业记录 |
| 6 推广与复购 | 让附近的人知道并愿意再来 | 抖音/朋友圈素材、附近客群话术、发布节奏、复购提醒 | 一周可执行内容包 |
| 7 事后经营分析 | 知道今天发生了什么、明天改什么、哪些顾客值得再触达 | 销量、客单、成本、时段、库存、顾客反馈、推广来源和复购记录，生成下一步动作 | 一张经营分析卡：继续 / 调整 / 暂停 / 复购 |

## 单场景页面结构

每个场景不要做成资料库，统一采用四段：

1. **先问 3—5 个关键问题**：城市、品类、预算、营业时段、当前阶段。
2. **给一张行动卡**：今天只做一件最重要的事。
3. **收材料再生成**：照片、价格、地址、证照状态等；没有材料时先给采集清单，不假装有真实结果。
4. **完成后给判断**：继续、调整、换点、暂停，并带到下一个场景。

## 第一期开做 / 不做

### 做

- 夜市小吃/饮品摊的七步路线。
- 城市和品类的基础问答。
- 候选点人流观察表与地图搜索跳转。
- 合规办理清单的“官方入口 + 待确认项”。
- 推车海报、菜单、朋友圈、短视频文案模板。
- 试营业和事后经营分析卡。
- 保存最近 10 次行动记录，能回看并修改。

### 不做

- 项目、任务、成员、权限、审批等企业管理能力。
- 一开始就覆盖餐饮、服装、维修、农产品等所有摊型。
- 自动承诺证照一定能办成、预测准确人流或保证收入。
- 直接代替地图、政务、支付和抖音平台。
- 复杂 BI 报表、长期 CRM 和多店协同。

## 用户调研计划

抖音内容只能作为线索，不能直接当作用户事实。第一轮采用“视频观察 + 访谈验证”双证据：

- 从“摆摊创业、夜市小吃、流动摊位、摆摊选址、摆摊一天”等关键词各采样 10 条公开内容。
- 记录：摊型、城市、启动成本、选址方式、最高频困难、真实使用工具、收入表述是否可核验。
- 把评论区高频问题单独编码，尤其关注“证照、城管、天气、进货、客流、复购、平台流量”。
- 访谈不设硬性人数门槛：优先争取 3—5 位摊主；如果实际只能找到 1—2 位，也先记录并明确证据不足，再用公开视频、评论区和线下观察补足问题清单。
- 任何抖音内容进入产品前，至少找 2 位真实摊主确认；涉及政策的内容只链接官方来源。

当前公开抖音搜索会要求登录，不能把搜索页展示内容当作已完成调研。需要用户提供可访问的视频链接，或由研究者登录后建立样本表，再进入下一轮产品决策。

## 精品 Skill 的采用规则

不直接搬运别人的 Skill。每个候选 Skill 先过四步：

1. 看它解决的是哪一个摊贩动作，而不是看包装描述。
2. 检查输入、输出、材料闸门、事实边界和失败处理。
3. 用同一份夜市小吃摊案例跑一遍，记录能否落地、是否会编造、是否太长。
4. 重写成“生意线场景卡”：保留方法，替换成我们的问法、证据要求、下一步动作和本地化限制。

优先寻找：选址调研、菜单/海报生成、短视频脚本、朋友圈运营、事后经营分析、证照信息整理；暂不引入泛项目管理、泛品牌战略和高阶企业 CRM Skill。

## 样本与验证口径

- **目标样本**：10 份小吃/饮品摊公开样本，来源可以是抖音视频、评论、探店记录和公开图文；城市可先从一个样本城市开始，但不写入产品固定规则。
- **访谈目标**：尽力完成 3—5 位；找不到时不伪造样本，不把“计划访谈”写成“已验证”。
- **一周试跑**：先找 1—2 位愿意试用的摊主即可形成第一轮反馈；5 位是理想目标，不是上线阻塞条件。
- **进入下一阶段的最低证据**：至少 10 份公开样本 + 1 位真实摊主完整跑完五个场景，或明确记录无法招募的原因。

## 成功信号

- 新用户在 5 分钟内完成首张“下一步行动卡”。
- 至少 60% 的测试用户完成“选址观察 → 试营业准备”两步。
- 访谈用户能复述自己下一步要做什么，而不是只说“内容很好”。
- 一周后至少 40% 的用户回来填写复盘卡，并产生一次调整动作。

## 下一步顺序

1. 先选一个样本城市，建立 10 份小吃/饮品摊公开样本；产品不绑定该城市。
2. 同步招募真实摊主访谈，目标 3—5 位；不足时如实记录并用公开资料补足。
3. 把七步路线压成第一期可点击原型。
4. 只先做“选品算账、选址调研、海报物料、试营业、事后经营分析”五个可用场景。
5. 先争取 1—2 位摊主跑通一周；5 位作为理想样本，不作为硬门槛，再决定是否扩展到证照、朋友圈和多摊型。
