# 生意线精品分类架构 v0.1

## 总原则

不按底座场景数量做网页，而按经营目标做分类精品：

`6 个分类 → 30 个左右精品工作流 → 100—300 个场景卡 → 数万条原始场景作为待筛选素材`

每个场景卡都复用分类页和工作流模板，只有复杂计算或图片编辑才开发专属交互。

## 第一阶段的页面数量

- 分类页：6 个
- 旗舰工作流：每类 2 个，共 12 个
- 场景卡：每个工作流 3—5 个，共 30—50 个
- 长尾场景：先开放 100—300 个，按搜索和真实使用逐批增加

## 分类页统一模板

1. 分类说明与适用经营阶段
2. 旗舰工作流
3. 高频场景卡
4. 行业/经营形态/渠道/交付物筛选
5. 搜索框
6. 最近使用与历史版本

## 工作流统一模板

`填写或上传事实 → 材料缺口 → 确认卡 → 生成成品 → 修改 → 导出/复制 → 保存版本 → 下一步`

## 场景卡准入规则

- 只服务个体户、小摊贩、小门店和轻量线上经营者；
- 一个场景只保留一个主要目标和一个主要成品；
- 输入能通过手填、上传或确认卡取得；
- 产出必须是文案、表格、报告、清单或图片方案；
- 与已有技能/专家不重复；
- 至少 3 条正向回归和 1 条诱饵样本；
- 缺资料时明确材料闸门，不用虚构数字填满页面。

## 第一批开发顺序

1. 采购与库存
2. 经营分析与复购
3. 选品与定价
4. 内容营销与活动
5. 获客与成交
6. 开店准备与合规
