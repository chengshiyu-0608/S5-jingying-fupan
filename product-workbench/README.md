# 生意线产品｜生意线垂直站工作台｜小微经营助手

本目录是“小微经营助手”六个独立 Skill 和后续组合专家的唯一工作目录。

## 目录规则

```text
00-总框架与共用规范/  总框架、共用协议、候选 Skill、统一设计和质量标准
S1生意方向与选品/     生意方向与选品独立 Skill、网页和测试产出
S2成本与定价/         成本与定价独立 Skill、网页和测试产出
S3选址与合规/         选址与合规独立 Skill、网页和测试产出
S4采购与库存/         采购与库存独立 Skill、网页和测试产出
S5获客与成交/         获客与成交独立 Skill、网页和测试产出
S6经营复盘与复购/     经营复盘与复购独立 Skill、网页和测试产出
```

## 每个技能子目录统一结构

```text
Sx技能名/
├── 01-业务定义/       定位、用户、边界、场景清单
├── 02-可复用参考/     GitHub/其他渠道参考、许可证记录、改写说明
├── 03-SKILL包/        SKILL.md、VERSION、agents、references、打包文件
├── 04-网页版/         独立网页版、页面说明、预览记录
├── 05-确认卡/         match_scene、字段、材料闸门、确认卡测试记录
├── 06-回归测试/       正向样本、诱饵、回归结果、缺陷分诊
└── 07-发布材料/       编辑页填写单、照抄版、头像、校验和
```

## 统一执行协议

所有技能遵循：

```text
用户请求 → 找场景 → 出确认卡 → 补材料 → 用户确认
→ 编译任务 → 生成结果 → 行动卡/成品 → 回执与下一步
```

确认卡连接器不可用时，不在网页或 Skill 中伪造确认卡；材料不足时，先显示缺口，不编造经营结果。

## 当前制作顺序

1. S2 成本与定价
2. S1 生意方向与选品
3. S6 经营复盘与复购
4. S4 采购与库存
5. S3 选址与合规
6. S5 获客与成交
7. 六个技能通过独立回归后，组合为“小微经营专家”

## 产出归档原则

- 新产出直接写入对应 S1～S6 子目录，不再散落在产品根目录。
- 共用文件只放在 `00-总框架与共用规范`，技能目录通过链接引用，不复制多份。
- 外部 Skill/模板只放在对应技能的 `02-可复用参考`，并记录来源、许可证、可复用范围和改写内容。
- 每个技能完成后，在其 `06-回归测试` 记录版本、样本和结论，再进入下一个技能。
- 六个技能合并专家时，专家级产出另建 `08-组合专家`，不覆盖六个独立技能的历史文件。
