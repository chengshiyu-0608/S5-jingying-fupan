# S2 定价决策工作流｜确认卡字段 v0.1

## 通用前置卡

- 这次要决定什么：算成本 / 测售价 / 记录实绩 / 复盘调价
- 经营对象：品名、规格、经营形态
- 当前阶段：准备开始 / 试营业 / 稳定经营 / 调整经营
- 用户已有材料：成本表、采购单、菜单、经营记录、平台结算单
- 交付偏好：比较表 / 计算卡 / 记录表 / 下一步行动卡
- 是否允许使用 AI 假设：默认允许用于示例，但不能写入最终实绩

## 分阶段字段

### 1. 选品与成本核算

品名、销售规格、售价（可空）、原料及采购价、每份用量、包装成本、损耗率或损耗金额、平台/支付费用、成本日期、来源。

### 2. 毛利与保本测算

售价、单份变动成本、日固定成本、目标日销量、折扣/套餐规则、平台抽佣、配送或摊位费用。

### 3. 经营记录

日期、营业时段、销量、实收、退款、原料实际耗用、报损、平台费用、顾客反馈、数据来源。

### 4. 复盘调价

复盘周期、目标指标、当前基准、已确认记录、候选动作（调价/改份量/换品/不变）、一次只改的变量、验证天数、停止条件。

## 缺失材料处理

- 缺少单份用量：输出“无法完成单份成本”，给出待补字段，不用行业均值代替。
- 缺少售价或实际收入：可以做成本结构，但不输出毛利结论。
- 缺少固定成本：可以算单份毛利，不输出保本单量。
- 只有一日数据：可做记录核对，不做趋势或稳定性判断。
- 用户确认修正数据：保留旧版本，标记修订时间和修订原因。
