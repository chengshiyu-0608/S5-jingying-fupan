# 定价决策工作流

## 目标

帮助流动摊位、固定摊位和小门店经营者完成四个连续决策：

1. 选品与成本核算；
2. 毛利与保本测算；
3. 经营记录；
4. 复盘调价。

这是产品层组合工作流，不假设市场存在“成本与定价”同名 Skill。可调用或借鉴的底层能力包括市场中的 `产品指标复盘`、`数据分析`、`分析报告复核`、`Excel表格`，以及内部确认卡协议。

## 必须遵守

- 任何阶段先展示确认卡，用户确认后才生成阶段结果。
- 分开标注用户事实、AI 假设、计算结果和材料缺口。
- 不把 AI 假设写入经营实绩；不虚构客流、销量、成本、政策、审批或利润。
- 单份毛利 ≤ 0 时，不输出保本单量，改为提示当前价格无法覆盖变动成本。
- 只有一日记录时不做趋势或稳定性判断；复盘时一次只改一个变量。
- 用户修改数字时保留旧记录，并标注修订时间和原因。

## 输出结构

每个阶段输出：本次输入、关键口径、阶段结果、完成标准、待补材料、下一步动作。数字结果给出计算式，结论使用“在当前输入下”措辞。

## 轻量公式

- 单份变动成本 = 原料成本 + 包装成本 + 单份损耗成本 + 按单变动费用。
- 单份毛利 = 售价 − 单份变动成本。
- 毛利率 = 单份毛利 ÷ 售价。
- 保本单量 = 日固定成本 ÷ 单份毛利，向上取整；毛利不为正时不可计算。

## 缺失材料处理

- 缺少每份用量：只输出待补字段，不估算单份成本。
- 缺少售价：可整理成本结构，但不输出毛利。
- 缺少固定成本：可输出单份毛利，不输出保本量。
- 缺少实际记录：不把计划销量当作实绩。

## 回归要求

至少覆盖正常四阶段、缺少单份用量、毛利为负、单日记录、冲突数据、重做、刷新恢复和市场来源边界 8 类用例。具体样例见 `../../06-回归测试/S2定价决策工作流-回归测试-v0.1.md`。
