# S2 定价决策工作流｜业务框架 v0.2

## 1. 产品定位

面向流动摊位、固定摊位和小门店经营者，把“这个品该不该卖、卖多少钱、卖多少才不亏、下一次怎么调”拆成四个连续决策。它是产品层工作流，不等同于市场中的单个原始 Skill。

## 2. 四阶段定义

| 阶段 | 经营问题 | 输入 | 输出 | 完成标准 |
|---|---|---|---|---|
| 1. 选品与成本核算 | 这个品的真实单份成本是多少？ | 品名、规格、采购价、每份用量、包装、损耗 | 单份成本表、缺口清单 | 每个成本项标注用户事实/待补/AI估算，公式可回算 |
| 2. 毛利与保本测算 | 这个售价是否覆盖变动成本和固定成本？ | 售价、单份成本、日固定成本、目标销量 | 毛利、毛利率、保本单量、情景表 | 至少完成基准情景；缺数据时不给确定结论 |
| 3. 经营记录 | 实际卖出后，事实表现如何？ | 日期、销量、实收、变动成本、报损、反馈 | 经营记录、口径检查、待补字段 | 记录可追溯到日期和来源，不把预测当实绩 |
| 4. 复盘调价 | 明天改价、改份量还是换品？ | 至少一轮经营记录与目标 | 调价/不调价建议、一个验证动作 | 只改一个变量，写明验证指标和停止条件 |

## 3. 统一计算口径

- 单份变动成本 = 原料成本 + 包装成本 + 单份损耗成本 + 平台/支付等按单变动费用。
- 单份毛利 = 售价 − 单份变动成本。
- 毛利率 = 单份毛利 ÷ 售价；售价为 0 或成本缺失时不计算。
- 保本单量 = 日固定成本 ÷ 单份毛利，向上取整；单份毛利 ≤ 0 时标记“当前价格无法覆盖变动成本”，不输出保本量。
- 套餐、折扣、平台抽佣必须单独列项，不能把折后价当原价。

## 4. 事实边界

1. 用户提供或明确确认的价格、成本、销量、损耗属于“用户事实”。
2. AI 为缺失项提供的默认值只能标为“AI 假设”，不得进入最终实绩。
3. 公式计算结果标为“计算结果”，并展示计算式或关键口径。
4. 缺少材料时先出“材料缺口卡”，不虚构客流、销量、成本、政策或利润。
5. 结论只回答当前数据能支持的范围，不承诺收入或盈利。

## 5. 状态机

`未开始 → 待确认 → 已确认 → 计算中/记录中 → 可执行 → 已完成 → 可复盘`

任一阶段可退回 `待补材料`；用户可选择“重新确认”而不覆盖已有记录。工作流默认只推进一步，完成标准未满足时不自动进入下一阶段。
