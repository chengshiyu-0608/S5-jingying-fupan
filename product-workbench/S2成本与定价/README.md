# S2 定价决策工作流

S2 不是假设市场存在一个“成本与定价”同名 Skill，而是把多个可复用底层能力编排成一条可暂停、可复核的工作流：

`选品与成本核算 → 毛利与保本测算 → 经营记录 → 复盘调价`

每一阶段都必须先过确认卡，再生成本阶段的行动卡；缺少真实成本、售价、销量或损耗时，只输出材料缺口和计算模板，不编造经营结果。

## 本目录交付物

- `01-业务定义/`：工作流目标、阶段输入输出、公式与边界
- `02-可复用参考/`：发布中心、GitHub 和其他渠道的复用核查
- `03-SKILL包/`：组合工作流 Skill 包与底层来源映射
- `04-网页版/`：可单独演示的定价决策工作流网页
- `05-确认卡/`：四阶段确认卡字段、缺失材料处理和状态流转
- `06-回归测试/`：正常出卡、缺材料、冲突数据和重做测试
- `07-发布材料/`：上架名称、介绍、触发词和来源声明
